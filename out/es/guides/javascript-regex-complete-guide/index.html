¿Qué caso límite pone a prueba matchAll?

Elige un valor inmediatamente fuera del requisito y añade, cuando proceda, un salto, un carácter Unicode, un valor vacío o un delimitador extra. Debe existir una única razón clara para aceptar o rechazar.

¿Qué debe medirse antes de usar lastIndex con entradas largas?

Mide tiempo, número de coincidencias, truncado de resultados, presión de memoria y timeout del Worker. Una muestra corta y rápida no demuestra seguridad ante una cadena larga o hostil.

¿Cuándo conviene abandonar la expresión regular?

Usa un parser o una biblioteca de dominio cuando el anidamiento, los escapes, la validación semántica o la portabilidad sean más importantes que una coincidencia textual compacta.
