# Privacy implementation

Core processing is local. There is no user account or application database. localStorage may contain recent pattern settings, flags, short text, test cases, theme preferences, and autosave preference when enabled. It never stores uploaded file contents. The interface provides a button to remove all local workbench data.

A share link may include a pattern, flags, active route, and text sample of at most 1,000 characters. The user must initiate the action and review the warning. Query values are not included in canonical URLs.

Analytics is disabled by default and must not receive patterns, text, file names, or capture results. AdSense and advertising cookies remain disabled at approval stage. If advertising is enabled, Google Privacy & Messaging or another certified CMP must handle applicable regional consent.
